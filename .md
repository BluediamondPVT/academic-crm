### Phase 1: Database Architecture (MongoDB Schemas)

Bhai, sabse pehle hum folder loop aur sharing ka logic database mein set karenge.

> **Copy this:**
> "Bhai, mujhe apne Next.js (App Router) ERP ke liye ek 'Digital Asset Management' (Mini Google Drive) banana hai. Iske liye MongoDB (Mongoose) ke schemas design kar do.
> Mujhe 2 Models chahiye (ya ek polymorphic model, jo tumhe best lage):
> 1. **Folder Schema:** Jisme `name`, `ownerId` (User ID), `department` (Role), `parentId` (null for root, ID for subfolders - for infinite loop), aur `sharedWith` (Array of Roles/UserIDs) ho.
> 2. **File Schema:** Jisme `name`, `fileUrl` (Cloudflare R2 link), `fileType` (extension/mime type), `size`, `folderId` (parent folder reference), `ownerId`, `department`, aur `sharedWith` ho.
> Schema ko aise optimize karna ki query fast ho jab hum kisi specific folder ke andar ka data (files + folders) fetch karein."
