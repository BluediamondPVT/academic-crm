Prompt 2: Backend APIs (The WebAuthn Logic)
Ab hum wo APIs banayenge jo phone ke scanner se baat karengi.

Copy this:
"Ab WebAuthn ke liye Next.js App Router (app/api/...) mein APIs likh. Mujhe 4 API routes chahiye:

/api/auth/register-challenge: Jo naye user ke liye registration challenge generate kare.

/api/auth/register-verify: Jo phone se aayi hui public key ko verify karke MongoDB mein save kare.

/api/auth/login-challenge: Jo registered user ke liye login challenge generate kare (after successful password verification).

/api/auth/login-verify: Jo login fingerprint ko verify kare aur session/JWT token return kare.
Code mein @simplewebauthn/server ke generateRegistrationOptions, verifyRegistrationResponse, generateAuthenticationOptions, aur verifyAuthenticationResponse methods ka proper use hona chahiye."

"Ab Frontend (React/Next.js Client Component) ka code likh. Mera login page dark theme mein hai jisme Email aur Password ka input hai aur ek 'LOGIN NOW' button hai.
Mujhe login function ka logic update karke do:

Agar login pass ho gaya, backend se check karo ki user ka Fingerprint (Passkey) registered hai ya nahi.

Agar registered NAHI hai: @simplewebauthn/browser ka startRegistration trigger karo, user se fingerprint lo, aur backend pe save kara ke login success karo.

Agar registered HAI: @simplewebauthn/browser ka startAuthentication trigger karo, fingerprint verify karo, aur direct dashboard pe redirect kar do.
UX smooth hona chahiye aur errors (jaise fingerprint cancel karna) properly handle hone chahiye."
